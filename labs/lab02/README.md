# Лабораторна робота №2 — Варіант 6
**Тема:** Розробка консольних утиліт для задач кібербезпеки  
**Індивідуальне завдання (Варіант 6):** Аудитор надійності та масок словників паролів

## 1. Встановлення залежностей
Перебуваючи в корені репозиторію `cybercecurity-python-labs`, активуйте віртуальне середовище та встановіть залежності:
```bash
source .venv/bin/activate
pip install -r requirements.txt
```

## 2. Структура вхідних даних (`labs/lab02/data/`)
Каталог `data_v06` із навчального архіву `lab2_data.zip` розміщується за шляхом:
- `labs/lab02/data/data_v06/passwords.txt` — вхідний текстовий файл зі словником паролів для аналізу.
- `labs/lab02/data/mask_audit_report.json` — підсумковий JSON-звіт аналізу структури та масок.

## 3. Інструкція запуску

Усі команди виконуються з кореневої директорії репозиторію через модуль `python -m`:

### Запуск Завдання 1 (Демонстрація ООП моделі):
Скрипт демонструє роботу моделі користувачів (`User`, `Admin`), безпечного хешування паролів (PBKDF2-HMAC-SHA256), валідації email через `@property`, контролю сесій (`Session`) з таймаутом 900 с та журналу аудиту подій (`AuditLog`):
```bash
python -m labs.lab02.main demo
```

### Запуск Завдання 2 (Аудитор словників паролів):
Запуск консольної утиліти з параметрами за замовчуванням:
```bash
python -m labs.lab02.main analyze --wordlist labs/lab02/data/data_v06/passwords.txt
```

Повний запуск із явним зазначенням усіх параметрів CLI:
```bash
python -m labs.lab02.main analyze \
    --wordlist labs/lab02/data/data_v06/passwords.txt \
    --min-length 8 \
    --top-masks 5 \
    --output-stats labs/lab02/data/mask_audit_report.json
```

## 4. Опис параметрів CLI для команди `analyze`
- `--wordlist` *(обов'язковий, `Path`)* — шлях до вхідного текстового файлу зі словником паролів.
- `--min-length` *(опціональний, `int`, за замовчуванням: `8`)* — мінімальна допустима довжина пароля; паролі, коротші за це значення, класифікуються як слабкі.
- `--top-masks` *(опціональний, `int`, за замовчуванням: `5`)* — кількість найпопулярніших масок для виведення у зведену таблицю консолі.
- `--output-stats` *(опціональний, `Path`, за замовчуванням: `labs/lab02/data/mask_audit_report.json`)* — шлях для збереження підсумкового звіту зі статистикою у форматі JSON.

## 5. Обробка помилок
Утиліта перехоплює системні помилки та винятки валідації аргументів (`FileNotFoundError`, `ValueError`, `PermissionError`, `OSError`):
- Якщо вказаний файл словника не знайдено або передано некоректні числові параметри (наприклад, `--min-length 0`), програма виводить зрозуміле повідомлення у потік `stderr` (`[ERROR] Помилка виконання: ...`) та завершує роботу з кодом виходу `1`.
